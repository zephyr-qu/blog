## 胡言乱语

**周刊结束对话**

这也很符合我三分种热度的性格，不过我还是坚持完成了这十期周刊。写周刊真的很不容易，一路探索的过程。尤其是我有些想说，但又觉得放上去不妥，还有就是没有什么可写。思考本就需要机遇和灵感，一味执拗的让自己从什么事情上领悟出大道理，我觉得这是不合适的。人总是随着时间变迁生出新的自我，对世界，对社会，对每件事，有一种新的认知。多年前我们拗口的古诗也穿插入我们的生活，成我们理解生活的用词感悟。但是无论是思考还是技术，我想我都是有收获的。

周刊的事先到这里，我觉得可以继续下去，不过可能会随心所欲，不会给自己既定要求。不止周刊，我还可能探索更多有趣的形式，丰富自己的博客。至此，感谢看过的各位，再见！

## 编程手札

**Claude Code 初体验**

> AI 代理直接植入终端。它能读文件、改代码、跑命令、自修复。

**动手体验**

:::steps

1. **安装与启动**

   ```bash
   # 安装
   npm install -g @anthropic-ai/claude-code
   
   # 配置 API Key
   export ANTHROPIC_API_KEY="sk-ant-xxxxx"
   
   # 启动后交互式登录
   claude
   ```

   国内不好访问，可以使用其他类似工具。

2. **初始化项目**

   我们使用AI创建一个个人名片网页，使用自然语言指令

   ```bash
   # 创建项目目录
   mkdir my-profile && cd my-profile
   
   # 启动 Claude Code
   claude
   
   # 初始化项目上下文
   /init
   ```

   描述需求（可以用 `/plan` 先让 AI 出方案）

   ```text
   帮我创建一个响应式的个人名片网页，包含：
   - 头像区域（圆形，带边框动画）
   - 姓名和职位标题
   - 三个技能标签（带渐变色）
   - 联系方式图标（GitHub、邮箱、Twitter）
   - 深色/浅色主题切换
   - 使用 Tailwind CSS，单文件 HTML
   ```

3. **使用MCP**

   安装 Context7 MCP

   ```bash
   # 本地服务器连接
   claude mcp add --scope user context7 -- npx -y @upstash/context7-mcp --api-key YOUR_API_KEY
   ```

   使用 context7 读取最新的 Tailwind CSS V4 文档

   ```bash
   最新的 Tailwind CSS v4 有哪些新特性可以运用到这个项目？use context7
   ```

   提示词末尾加 `use context7`，可以确保 AI 调用文档检索

4. **使用 Skills**

   安装 `ui-ux-pro-max`  Skill

   ```bash
   # 下载 Skill 文件
   # 解压到项目目录
   mkdir -p .claude/skills
   
   # 激活 Skill
   /claude skill ui-ux-pro-max
   ```

   使用 ui-ux-pro-max 优化页面UI

   ```bash
   基于极简主义风格，优化项目页面的 UI 布局和配色
   ```

   

5. **实用技巧**

   - 用 `!` 即时执行 Bash 命令
   - 用 `@` 读取文件，引用上下文
   - 双击 ESC，快速回退操作

   

6. **小结**

   第一次接触终端类AI，还是很惊艳的，也许未来没有程序员这个职业也说不定呢。

:::
