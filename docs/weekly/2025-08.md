## 胡言乱语

**苦难不是娱乐**

最近流行起了一种短视频，前面是老百姓的苦难，后面是歌。起初我有些欣慰，终于有人为这些人发声了。后来越来越多，我意识到不对，苦难似乎成为了流量工具。评论区多少对国家对社会的嘲讽和抱怨，没有任何人注意到那些底层真正的悲剧，他们在意的不过是自己所处悲惨现实斩断了他们浮夸的梦。再后来不同国家的“苦难”相继出现。我感到一阵恶心。不过是利用底层人民的苦难，进行舆论对抗，成为了国家舆论场上博弈的工具。对此，我是极其反感的。我们最初的目的不是发现问题，解决问题吗？我们不是为了这些人的苦难发声吗？我们不是为了社会越来越好吗？我反对一切夸大，虚假的传播，反对苦难成为流量成为工具，反对苦难娱乐化。但——我的反对没有力量，而且我的声音并不能让那些人过上好日子。

## 编程手札

**Vite 初体验**

> **Vite** 是由 Vue.js 作者 尤雨溪 开发的下一代前端构建工具。

**动手体验**

:::steps

1. **创建项目**

   创建一个 Vite 项目

   ```bash
   pnpm create vite
   ```
   
   随后通过交互选择即可创建成功
   
   
   
2. **启动项目**

   ```bash
   cd my-vite-app
   pnpm install
   pnpm dev  # 启动开发服务器
   ```

   打开浏览器访问 `http://localhost:5173`，可以看到页面

   

3. **项目结构**

   Vite 的项目结构非常直观

   ```text
   my-vite-app/
   ├── node_modules/
   ├── public/             # 静态资源，直接复制到根目录
   ├── src/                # 源代码
   │   ├── assets/         # 被 Vite 处理的资源 (图片，css)
   │   ├── components/     # 组件
   │   ├── App.vue         # 根组件
   │   └── main.js         # 入口文件
   ├── index.html          # HTML 入口
   ├── package.json
   └── vite.config.js      # 配置文件
   ```

   

4. **核心配置体验**

   Vite 的配置很简洁

   ```javascript
   import { defineConfig } from 'vite'
   import vue from '@vitejs/plugin-vue'
   import path from 'path'
   
   export default defineConfig({
     plugins: [vue()], // 插件系统
     
     resolve: {
       alias: {
         '@': path.resolve(__dirname, './src'), // 配置 @ 别名
       },
     },
     
     server: {
       port: 3000,          // 自定义端口
       open: true,          // 启动后自动打开浏览器
       proxy: {
         '/api': {
           target: 'http://backend.com',
           changeOrigin: true,
           rewrite: (path) => path.replace(/^\/api/, ''),
         },
       },
     },
   })
   ```

   

5. 其他特性

   *   **TypeScript:** 原生支持，无需额外配置 Loader。
   *   **CSS 预处理:** 安装 `sass` 或 `less` 后即可直接在 CSS 中使用。
   *   **环境变量:** 使用 `.env` 文件，通过 `import.meta.env` 访问。
   
   


6. 总结

   vite 已经成为了前端工程构建的不二选择，期待它”绣“化的后的表现

:::
