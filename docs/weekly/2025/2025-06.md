## 胡言乱语

**平衡AI在个人创作中的参与度**

这是一个发人深省的问题。在进行创作时，究竟该如何平衡AI在个人创作中的参与度呢？想必很多人都明白，应当以个人为主、AI为辅，这似乎是不言而喻的道理。 然而，当我们处于能力不足的学习阶段，AI创作的水平远远超越我们时，我们又当如何？比如，你有一个选题，结果AI写出来的比你更加完美，你丝毫没有补充的余地，难免会涌起一种无力感。更令人唏嘘的是，当我带着这个话题去询问AI时，它的分析竟比我还要透彻。这不禁让我陷入更深的思考，在创作这条道路上，该如何在借助AI力量的同时，保持并提升自己的创作能力呢？

## 编程手札

**Nushell 初体验**

> 一个比较现代化 Shell。由 Rust 语言编写，特长是处理数据，也可用于日常。



**动手体验**

:::steps

1. **Shell 安装**

   使用 scoop 安装 nushell 

   ```bash
   scoop install nushell
   ```

   

2. **动手体验**

   输入 `ls` 回车

   ```bash
   ls
   
   ╭───┬────────────┬──────┬────────┬────────────────╮
   │ # │    name    │ type │  size  │    modified    │
   ├───┼────────────┼──────┼────────┼────────────────┤
   │ 0 │ 2025-00.md │ file │  256 B │ 2 days ago     │
   │ 1 │ 2025-01.md │ file │ 6.2 kB │ 28 minutes ago │
   │ 2 │ 2025-02.md │ file │ 4.1 kB │ 13 minutes ago │
   │ 3 │ 2025-03.md │ file │ 6.3 kB │ 11 minutes ago │
   │ 4 │ 2025-04.md │ file │ 4.8 kB │ a month ago    │
   │ 5 │ index.md   │ file │  229 B │ a month ago    │
   ╰───┴────────────┴──────┴────────┴────────────────╯
   ```

   会输出一个表格，可以看到 `name`, `type`, `size`, `modified` 都是是独立的列。

   

3. **处理文件**

   nushell 内置了许多用于数据处理的命令，用来处理复杂数据

   ```bash
   # 找出大于 1KB 的文件，只显示名字
   ls | where size > 1kb | select name
   
   ╭───┬────────────╮
   │ # │    name    │
   ├───┼────────────┤
   │ 0 │ 2025-01.md │
   │ 1 │ 2025-02.md │
   │ 2 │ 2025-03.md │
   │ 3 │ 2025-04.md │
   ╰───┴────────────╯
   ```

   

4. **常用命令速查**

   nushell 有许多内置命令，语法统一

   | 任务     | Bash/Zsh 命令 | Nushell 命令      | 说明                                    |
   | :------- | :------------ | :---------------- | :-------------------------------------- |
   | 查看帮助 | `man ls`      | `help ls`         | 内置帮助非常详细                        |
   | 当前路径 | `pwd`         | `pwd`             | 一样                                    |
   | 切换目录 | `cd`          | `cd`              | 一样                                    |
   | 查看文件 | `cat`         | `open`            | 自动识别 json, toml, yaml 等格式        |
   | 查找内容 | `grep`        | `grep` 或 `where` | `where` 用于结构化数据，`grep` 用于文本 |
   | 统计行数 | `wc -l`       | `length`          | 计算列表长度                            |
   | 环境变量 | `echo $PATH`  | `$env.PATH`       | 环境变量在 `$env` 中                    |

   

5. **个性化配置**

   nushell 的配置文件也是 nushell 代码

   ```bash
   # 查看 配置文件的位置
   $nu.config-path
   
   # 通常在 ~/.config/nushell/config.nu
   ```

   可以设置别名 (`alias`)、提示符 (`prompt`)、快捷键等个性化设置

   

7. 小结

   nushell 是一个强大的提示友好的shell ，在日常交互方面也没有明显的短板。

:::
