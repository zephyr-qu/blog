# 二、 唯物辩证法：事物发展的规律  

## 三大核心规律  
1. **对立统一规律**：事物内部矛盾（如生产力与生产关系）推动发展。  
2. **量变质变规律**：量的积累引发质的飞跃，如工业革命推动社会形态变革。  
3. **否定之否定规律**：新事物通过扬弃旧事物而发展，如资本主义取代封建制度。  

## 运动与矛盾的普遍性  
- **运动是物质的根本属性**，静止是运动的特殊状态。  
- **矛盾无处不在**，贯穿事物发展始终。例如，阶级社会的剥削与被剥削矛盾推动历史进步。
