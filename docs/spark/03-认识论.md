# 三、马克思主义认识论：实践是真理的源泉  

## 实践与认识的辩证关系  
- **实践**：人类改造世界的活动（如生产劳动、科学实验）。  
- **认识**：通过实践对客观规律的反映。  
  马克思强调，真理的检验标准是实践。例如，依据对植物生长规律的认识去种植，收获丰歉会反过来证实或证伪原有的认识——实践使思维与存在的同一性得到检验，也回应了康德“物自体不可知”的设问：人并非只能停留在现象背后猜测，而是在改造对象的过程中不断逼近客观规律。  

## 真理的阶级性与客观性  
- 真理在内容上是客观的（如科学规律），但在应用上具有阶级性。  
- 马克思主义公开代表无产阶级利益，同时承认自身需在实践中不断修正发展。
